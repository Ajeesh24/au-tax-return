# ATO return labels — quick map

Maps figures to where they go in **myTax** (online) and the paper return. myTax is
screen/section based; the paper return uses item numbers. Use these names in the
output sheet so the user can match them on screen. **Verify label wording against the
live myTax for the user's year — the ATO adjusts wording between years.**

## Income

| Figure | myTax section | Paper item |
|---|---|---|
| Salary & wages, tax withheld | Income statements and payment summaries | Item 1 |
| Allowances, earnings, tips | Income statements / Item 2 | Item 2 |
| Australian interest | Interest | Item 10 |
| Dividends (franked, unfranked, franking credits) | Dividends | Item 11 |
| Rent (income & deductions) | Rent | Item 21 |
| Capital gains | Capital gains or losses | Item 18 |

## Rent sub-labels (within the Rent section)

Gross rent; then deductions: Interest on loans; Capital works (Div 43); Depreciation
/ decline in value (Div 40); Council rates; Water charges; Land tax; Insurance;
Property agent fees/commission; Advertising; Repairs & maintenance; Borrowing expenses;
Body corporate; Cleaning; Gardening; Pest control; Sundry rental expenses. Enter each
at the **owner's share**.

## Offsets / adjustments / other

| Figure | myTax section |
|---|---|
| Private health insurance rebate | Private health insurance |
| Medicare levy surcharge answer | Medicare (private hospital cover Y/N + dates) |
| Medicare levy reduction/exemption | Medicare |
| Spouse details | Spouse |
| HELP/HECS balance | prefilled; repayment auto-calculated |
| Low income tax offset (LITO) | Auto-applied by ATO — do not enter |

> LITO and the tax-free threshold are applied **automatically** by the ATO — the user
> does not type them in. The estimate includes them so the refund figure is realistic,
> but the form-filling sheet should not list them as fields to enter.
